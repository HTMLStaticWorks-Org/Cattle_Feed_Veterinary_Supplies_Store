# FarmCare — Local Image Assets

The website photographs are bundled locally in the `assets/` directory as WebP files. They are used directly by the HTML pages and interactive Home 2 and Services components. No Pexels or other external image CDN URLs are required for the page photographs.

The local photo library includes page-specific image sets for Home 1, Home 2, About, Services, Products, Livestock Care, Contact and FAQ. The Services moving gallery has five different photographs in each pass; the second copy of the same five-photo sequence is only for the seamless animation loop.

Replace or supplement these local files if the business later supplies its own licensed photography.
