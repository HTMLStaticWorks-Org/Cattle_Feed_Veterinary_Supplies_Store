The eight photographs in `assets/home-capability-01.webp` through `assets/home-capability-08.webp` were generated specifically for this website as farm-themed visual assets and cropped into individual high-resolution WebP files.

- `home-capability-01.webp`: dairy cattle in a clean barn
- `home-capability-02.webp`: farmer inspecting green fodder
- `home-capability-03.webp`: veterinarian caring for a calf
- `home-capability-04.webp`: grain storage and handling equipment
- `home-capability-05.webp`: poultry housing and flock care
- `home-capability-06.webp`: hay and fodder storage
- `home-capability-07.webp`: goats and sheep grazing
- `home-capability-08.webp`: tractor working in crop fields

These eight images are used only in the two new homepage sections. No external image URL is required for these sections.

- `contact-dairy.webp`: dairy cattle feeding in a clean barn; reused as the fifth featured panel in Home 2. It was not referenced elsewhere in the previous website pages.
